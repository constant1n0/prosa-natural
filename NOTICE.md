# Avisos de terceros

prosa-natural reutiliza o prevé adaptar material de los proyectos con aviso MIT incluidos a continuación. No se distribuyen tal cual: las decisiones y sus límites se indican en `docs/auditoria.md`.

Las ideas tomadas de Wikipedia:Signs of AI writing (revisión 1376018375, CC BY-SA 4.0) se citan como referencia, pero no se copian sus ejemplos. kjmagnan1s/anti-slop (`a3807e5d9030738eb66cb61df47844e87963cc43`, MIT) también se usa solo como fuente de ideas —portabilidad, presupuesto de reglas y prosa de control—, sin copiar texto ni extender su licencia a material de terceros.

Las versiones consultadas están fijadas a un commit concreto. Para reproducirlas:

```sh
git clone https://github.com/blader/humanizer upstream/humanizer
git -C upstream/humanizer checkout 9862685f575c65a8247f90369951df1b3416e3d6

git clone https://github.com/avectats7/anti-ai-writing upstream/anti-ai-writing
git -C upstream/anti-ai-writing checkout eeb42e5127d844d06568b15b198b23c4a8339d88

git clone https://github.com/adewale/anti-slop-writing upstream/anti-slop-writing
git -C upstream/anti-slop-writing checkout 53370ff70b6d1da376e053cf144d39dca8d64f9e

git clone https://github.com/vicentealvarezasencio/humanamente upstream/humanamente
git -C upstream/humanamente checkout 1447b618301e4b17dc5f88335128ca2522964ca1
```
